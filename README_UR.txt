# مدرسہ / اسکول مینجمنٹ سسٹم — Premium Offline v2
سفید + گرے + پیلا (Yellow) ڈیزائن · مکمل آف لائن · ہر مدرسہ اور اسکول کے لیے

## چلانے کا طریقہ (Windows)
1. ZIP کو ایک فولڈر میں Extract کریں۔ Python 3.11+ انسٹال ہو۔
2. `START.bat` پر ڈبل کلک کریں۔ براؤزر خود کھلے گا (http://127.0.0.1:8000)۔
3. بند کرنے کے لیے کالی ونڈو بند کر دیں۔

## بالکل بغیر انٹرنیٹ انسٹال (Offline install)
انٹرنیٹ والے کسی کمپیوٹر پر `MAKE_WHEELS_ONLINE_PC.bat` ایک بار چلائیں۔ یہ `wheels` فولڈر بنائے گا۔
پورا فولڈر (wheels سمیت) آف لائن کمپیوٹر پر کاپی کریں اور `START.bat` چلائیں — انٹرنیٹ کی ضرورت نہیں۔

## شامل فیچرز
- ڈیش بورڈ: طلبہ/اساتذہ/کلاسیں، آج کی حاضری، ماہانہ وصولی و اخراجات، 6 ماہ کا چارٹ، اعلانات، سالگرہ۔
- داخلہ و طلبہ: تصویر، رول نمبر خود کار، ب فارم، بورڈ (وفاقی/غیر وفاقی)، رہائش (مقیم/غیر مقیم)، پروفائل، فلٹر، Excel/CSV ایکسپورٹ،
  اگلی کلاس میں ترقی / فارغ التحصیل، شناختی کارڈ (ایک یا پوری کلاس)۔
- اساتذہ: مکمل پروفائل، تنخواہ کی ادائیگی اور تنخواہ سلپ، حاضری۔
- کلاسیں: کلاس ٹیچر، ماہانہ فیس، کلاس رپورٹ پرنٹ۔
- حاضری: پوری کلاس کی ایک شیٹ (سب حاضر بٹن)، ماہانہ حاضری کا گرڈ، اساتذہ کی روزانہ/ماہانہ حاضری۔
- فیس و فنڈ: پرنٹ رسید، بقایا جات / ڈیفالٹرز رپورٹ، ہدیہ/فنڈ الگ، فلٹر۔
- اخراجات اور سالانہ آمدن-خرچ رپورٹ۔
- نتائج: کلاس وار نمبر ایک ساتھ، مضمون وار، خود کار گریڈ و فیصد، پوزیشن، رزلٹ کارڈ (ایک یا پوری کلاس)۔
- جامع رپورٹس: کلاس/امتحان/ماہ فلٹر، گریڈ، پوزیشن ہولڈرز، CSV۔
- اعلانات، پاس ورڈ تحفظ (اختیاری)، لوگو اور ادارے کی معلومات (ہر پرنٹ کے لیٹر ہیڈ پر)۔
- بیک اپ: روزانہ خود کار، ایک کلک بیک اپ، ڈاؤن لوڈ، بیک اپ سے بحالی (`backups` فولڈر)۔
- کوئی CDN / آن لائن فائل نہیں؛ چارٹس بھی مقامی ہیں۔

## پرانا ڈیٹا
موجودہ `madrasa.db` برقرار ہے۔ پہلی بار چلنے پر نئے کالم/ٹیبل خود بنتے ہیں؛ کوئی ریکارڈ حذف نہیں ہوتا۔ پھر بھی پہلے `BACKUP.bat` چلا لیں۔
فیس کے پرانے ریکارڈ پر تاریخ نہیں تھی، اس لیے وہ ماہانہ چارٹ میں نہیں آتے مگر "کل" میں شمار ہوتے ہیں۔

## ہر ادارے کے لیے الگ ڈیٹا
ہر مدرسے/اسکول کے لیے پورے فولڈر کی الگ کاپی استعمال کریں (الگ madrasa.db)۔ پروگرام کو انٹرنیٹ پر پبلک سرور کے طور پر نہ چلائیں۔

## نستعلیق فونٹ
لائسنس یافتہ Jameel Noori Nastaleeq سسٹم میں انسٹال ہو تو خود استعمال ہوگا، یا فائل `static/fonts/Nastaleeq.ttf` کے نام سے رکھ دیں۔

## معلوم حدود
- بائیومیٹرک فنگر پرنٹ مشین کے لیے مخصوص SDK چاہیے؛ حاضری دستی ہے۔
- پاس ورڈ بھول جائیں تو بحالی کا آسان طریقہ نہیں۔
